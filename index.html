  1. 2026 - 2 Hour Narrative Game Jam

    Homebrew Antiques

    The project

    Homebrew Antiques is a whimsical narrative game. You wake up as a goblin, cursed by a witch Karen, and have to run your business with your new goblin mindset. Your choices shape the story, and some of them get people killed, but at least you end up a happy goblin.

    My role

    I was both the programmer and the team manager.
    As manager, I split the work into tasks that matched each member's strengths and kept the scope achievable.
    As programmer, I designed and implemented the code behind the game and 3 gimmicks, one for each customer, one of which is an an inventory system.
    The finished game is published on itch.io.
    After the jam, I released version 1.2 with small code fixes, and the code is public on GitHub.

    Tools used

    • Ren'py
